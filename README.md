# Sophie Lancaster Foundation: news and In Memoriam

The news posts and In Memoriam entries for the Sophie Lancaster Foundation website. Write and edit them in the editor at **/admin** on the website, not here.

- `content/posts/`: one Markdown file per post.
- `content/memoriam/`: one Markdown file per In Memoriam entry (Support Us > In Memoriam).
- `assets/uploads/`: images added in the editor.

Every change here rebuilds the website (see `.github/workflows/rebuild-site.yml`). The site's own code is kept in a separate private repo.
